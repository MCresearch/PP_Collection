ONCV pseudopotentials for warm dense matter boron (B), aluminum (Al), and silicon (Si) used in T. Chen, et al., "First-Principles Prediction of Shock Hugoniot Curves of Boron, Aluminum, and Silicon from Stochastic Density Functional Theory".​​

​​They are generated by ONCVPSP.​​

​​The naming convention for each pseudopotential file is as follows: ElementName_ValenceElectrons_RecommendedEnergyCutoff_PseudopotentialCutoffRadius_DefaultXCFunctional
